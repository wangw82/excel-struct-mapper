# Documentation

This directory describes Excel Struct Mapper's public behavior and design boundaries. Documentation will be versioned with the public API after tagged releases begin.

## User Guides

- [Getting started](getting-started.md) covers installation status and runnable examples.
- [Runnable examples](../examples/README.md) cover layouts, recursive groups, extensions, validation, and XLSX files.
- [Core concepts](concepts.md) explains rows, metadata, binding, conversion, and diagnostics.
- [Tag reference](tags.md) lists block, field, and application-owned tag syntax.
- [Mapping rules](mapping-rules.md) defines deterministic mapping and validation behavior.
- [FAQ](faq.md) answers compatibility, safety, and resource questions.

## Maintainer Guides

- [Architecture](architecture.md) describes module boundaries, data flow, and constraints.
- [Contributing](../CONTRIBUTING.md) defines development and review requirements.
- [Governance](../GOVERNANCE.md) defines roles and decisions.
- [Security](../SECURITY.md) defines private reporting and supported versions.
- [Support](../SUPPORT.md) defines public support scope.

## Conventions

- “Must” and “must not” identify compatibility or security constraints.
- Examples track the current source but may change before the first release.
- Versioned API documentation and release notes take precedence for a tagged release.
